# 35. Moderation: Abgleich des Entwurfs `MODERATION.md` mit dem Gebauten (03.11.2026)

Teil des Konzepts (`docs/CONCEPT.md`, Abschnitt 35). Grundlage: der Entwurf `docs/MODERATION.md` (Branch
`feature/moderation-konzept`, Stand Oktober 2026, Anforderungen F-200 … F-212), Konzept 4 (Kommentare, Melden),
Konzept 18 (Admin-Bereich, F-230 … F-243, F-294 … F-296) und der Code (`worker/reports.ts`, `worker/moderation.ts`,
`worker/locks.ts`, `worker/admin*.ts`, `worker/covers.ts`, `src/content/legal.ts`). Der Entwurf entstand vor K 18;
vieles daraus ist inzwischen anders oder besser gelöst. Dieser Abschnitt ersetzt den Entwurf: **was schon gilt, was
fehlt und was wir empfehlen.** Die Rechtshinweise sind eine Einschätzung, keine Rechtsberatung. Der Branch
`feature/moderation-konzept` kann nach dem Merge gelöscht werden. Seine Nummern F-200 … F-212 werden nicht
übernommen; neue IDs reserviert, wer ein Feature startet.
